A minimal, clean block theme for blogs and magazines.

== Description ==

Naturaly is a single-column block theme focused on reading: black and white
typography, one green accent, generous whitespace and system fonts for fast
loading. It ships with a Dark style variation.

== Changelog ==

= 1.2.0 =
* Removed the built-in SEO module (meta description, canonical URLs, Open Graph, Twitter cards, JSON-LD, 404 noindex). Use an SEO plugin instead.

= 1.1.0 =
* SEO: meta description, canonical URLs for archives, Open Graph and Twitter cards.
* SEO: JSON-LD structured data (WebSite, Organization, WebPage, BlogPosting, BreadcrumbList).
* SEO: 404 pages are set to noindex; the blog home now has a real H1.
* Performance: theme CSS is inlined, emoji scripts and unnecessary head links removed.

= 1.0.0 =
* Initial release.
